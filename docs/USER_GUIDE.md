# User Guide

1. Navigate to the homepage and register.
2. An admin (database level) must set `approved = true` in MongoDB for your user record.
3. Log in.
4. You will see the Dashboard with total extracted articles.
5. Click 'Articles' in the navigation bar to browse all news.
6. Use the Search bar to find specific topics.
7. Use the Language dropdown to filter by English, Arabic, or Russian.
8. Click an article title to read the full cleaned text.
